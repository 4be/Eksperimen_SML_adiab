# Eksperimen Sistem Machine Learning

Repository ini memuat eksperimen manual menggunakan template Dicoding,
dataset UCI Banknote Authentication, hasil preprocessing, serta fungsi
otomatisasi preprocessing. Dataset memiliki 1.372 sampel, 4 fitur numerik, dan
target klasifikasi biner.

Sumber dataset:
https://archive.ics.uci.edu/dataset/267/banknote%2Bauthentication

Jalankan notebook `preprocessing/Eksperimen_adiab.ipynb` dari folder
`preprocessing`. Hasil siap latih tersedia pada
`preprocessing/banknote_preprocessing.csv`.
